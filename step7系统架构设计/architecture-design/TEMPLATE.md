# ARCHITECTURE.md 模板

> 使用规则：
> - 标准级别使用本模板主体；确实不涉及的章节写"不适用：理由"，不留空白章节。
> - 精简级别使用文末精简版模板。
> - 完整级别使用本模板全部章节。
> - 状态标记沿用五状态体系（confirmed / pending / conflict / assumption / deferred）；"待验证"条目用 pending + 验证标记，并注明验证方式或 TV 编号。
> - 架构图用 Mermaid 内嵌，不单独建图片文件。
> - 每项设计须可追溯：FR-xxx / NFR-xxx（需求）、PG-xxx / FLOW-xxx（产品设计）、TV-xxx / DC-xxx（第六阶段）、本轮 DEC-xxx。
